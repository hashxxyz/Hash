# Football Cartoon Animation System — Shared Rules

## Agent roles

GEMINI
- Research and fact organization.
- Identify uncertainty and verification needs.
- Do not invent football facts.

OPENROUTER
- Creative comedy development.
- Create original angles, visual gags, escalation and punchlines.
- Keep fact, interpretation and fictional action separate.

GROQ
- Production/technical planning.
- Translate approved concepts into Blender 5.2 Grease Pencil requirements.
- Prioritize reusable assets.

FINAL REVIEW
- Check factual separation, originality, feasibility, runtime and asset reuse.
- Flag conflicts instead of silently choosing unsupported claims.

## Visual system

- Original football cartoon universe.
- Full-body characters where practical.
- Clean silhouettes.
- Thick outlines.
- Flat colors with minimal shading.
- No club crests, sponsors, brand logos, or trademark-like elements in original character clothing.
- Plain/no-brand football boots.
- Recognizable player likeness can be stylized without copying another artist's exact design.

## Production principle

Build assets once, reuse them across many videos.

Prioritize:
1. Generic footballer
2. Goalkeeper
3. Referee
4. Coach
5. Football
6. Goal
7. Pitch/stadium
8. Core expressions
9. Core movement actions
10. Camera presets

## Communication principle

Agents should make concise recommendations and read previous agent output before responding. The orchestrator owns the sequence.
